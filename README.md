# Mayotter

複数のX（旧Twitter）アカウントやタイムラインを、ひとつの画面に。

Mayotterは、複数カラムでXを利用できるWindows向けデスクトップアプリです。ワークスペースやDockを使って、自分に合った表示に整理できます。

## 主な機能

- 複数アカウント・複数カラムに対応
- Work（ワークスペース）でカラムを整理・切り替え
- Dockでコンパクトに表示
- 非表示ページの休止など、メモリ・CPU使用量に配慮した設計
- 日本語・英語・簡体字中国語に対応
- 音声投稿向けの試験的なAIノイズキャンセリング

## ダウンロード

**[最新版をダウンロード（Releases）](https://github.com/mayomayowyi/Mayotter/releases/latest)**

ZIP版はダウンロード後に解凍し、`Mayotter.exe`を起動してください。

起動したらアカウントとカラムを追加して利用できます。

## ご利用にあたって

MayotterはXの公式アプリではありません。X側の仕様変更などにより、一部機能が動作しなくなる場合があります。
