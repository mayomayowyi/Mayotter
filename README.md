# Mayotter

複数のX（旧Twitter）アカウントやタイムラインを、ひとつの画面に。

Mayotterは、複数カラムでXを利用できるWindows向けデスクトップアプリです。

ワークスペースやDockを使って、自分に合った表示に整理できます。動作の軽さや使いやすさにもこだわっています。

## 主な機能

- 複数アカウント・複数カラムに対応
- Work（ワークスペース）でカラムを整理・切り替え
- Dockによるコンパクトな表示
- メモリ・CPU使用量を抑えるための最適化
- 日本語・英語・簡体字中国語に対応
- 音声投稿と試験的なノイズキャンセリング

## ダウンロード

**[最新版をダウンロード（Releases）](https://github.com/mayomayowyi/Mayotter/releases/latest)**

ZIP版はダウンロード後に解凍し、`Mayotter.exe`を起動してください。

起動後は「+X」から新規アカウントを追加し、自由にカスタマイズできます。
