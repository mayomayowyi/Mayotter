# Mayotter

複数のX（旧Twitter）アカウントやタイムラインを、ひとつの画面に。

Mayotterは、複数カラムでXを利用できるWindows向けデスクトップアプリです。

ワークスペースやDockを使って、自分に合った表示に整理できます。動作の軽さや使いやすさにもこだわっています。

TweetDeckのようにX（Twitter）のタイムラインを複数カラムで表示したい方や、TweetDeckの代わりになるWindowsアプリを探している方にも向いています。

## 主な機能

- 複数アカウント・複数カラムに対応


- Work（ワークスペース）でカラムを整理・切り替え
- Dockによるコンパクトな表示
- メモリ・CPU使用量を抑えるための最適化
- 日本語・英語・簡体字中国語に対応
- 音声投稿と試験的なノイズキャンセリング

## 使い方

1. **Mayotterを起動する**  
   初回起動時に言語選択画面が表示された場合は、日本語・English・简体中文から選択します。
2. **Xアカウントを追加する**  
   「**+X**」からアカウントを追加し、表示された画面でXにログインします。
3. **カラムを追加する**  
   カラム追加の操作から、表示したいタイムラインや検索などを選択します。複数のカラムを並べて利用できます。
4. **Workを切り替える**  
   「**Work**」で作業内容ごとにワークスペースを作成・切り替えできます。
5. **Dock・Flipを使う**  
   「**Dock**」ではウィンドウを画面端に収納でき、「**Flip**」ではカラムを1つずつ大きく表示して切り替えられます。
6. **検索・音声機能を利用する**  
   カラム内での検索は `Ctrl+F` から利用できます。音声投稿や録音なども必要に応じて使用してください。
