# Mayotter

複数の X（旧Twitter）アカウントを、複数カラムで表示する Windows 向けアプリです。

Python / PySide6 / Qt WebEngine で実装しています。

## 必要環境

* Python 3.10 以上
* PySide6 6.6.1 以上

## インストール

```bash
pip install -e .
```

## 起動

```bash
python -m src.app.main
```
